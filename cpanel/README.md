# README about cpanel folder

## ioc_checksessions_files.sh

The file `ioc_checksessions_files.sh` is detection script to look for indicators of compromise, and checks for sessions in the filesystem
regarding to CVE-2026-41940 , for more help see:
[Security: CVE-2026-41940 - cPanel & WHM / WP2 Security Update 04/28/2026](https://support.cpanel.net/hc/en-us/articles/40073787579671-Security-CVE-2026-41940-cPanel-WHM-WP2-Security-Update-04-28-2026)


## check_whm_api_tokens.sh

The file `check_whm_api_tokens.sh` is for WHM API Token Security Review Script. To Review WHM API tokens after a security incident or during routine audits.

This script does not modify or delete anything.
